📖 Notice d'utilisation et de paramétrage

Lire le paysage

  • Chaque cellule est un format hypothétique : (nBit, w) ⇒ mantisse = nBit − n_sign − surcoût − w.
  • Hauteur et couleur = qualité d'encodage Q = moyenne harmonique(portée, précision), en échelle log. Q équilibre « couvrir beaucoup de décades » (exposant) et « être précis » (mantisse).
  • Ligne dorée : la crête d'optimum — pour chaque nBit, le w qui maximise Q. C'est la ligne que les formats historiques longent.
  • Ligne cyan : votre curseur lié r. Faites-la glisser : si elle quitte la crête, vous êtes sous-optimal.
  • + blancs : bfloat16, half, float32, float64, x87-80, float128.
  • Survol d'une cellule : nBit, w, mantisse, portée (en puissances de 10), précision (chiffres décimaux), Q.

Paramétrer

  • nCat = 2 : virgule fixe (signe + mantisse, pas d'exposant) → paysage plat : aucune découpe possible, la précision pousse linéairement mais la portée reste minuscule. La leçon visuelle : sans exposant, pas de compromis, pas d'optimum — juste un mur.
  • nCat = 3 : le monde IEEE 754 (signe + exposant + mantisse) → le paysage classique avec sa crête.
  • nCat = 4 ou 5 : catégories supplémentaires (mantisse étendue, bits de garde, tag de format…). Modèle pédagogique : chaque catégorie en plus coûte 1 bit de balise (surcoût). Effet visible : le paysage « recule » d'un bit, la crête se décale, les petits formats deviennent impossibles.
  • n_sign = 0 : nombres uniquement positifs (un entier non signé de mantisse, gain d'un bit de précision). n_sign = 2+ : gaspillage volontaire (signe + payload NaN, par ex.).
  • Caméra : glisser = orbiter · molette = zoomer · double-clic = vue de départ.

Visualiser en local sur votre PC

Ce fichier est du pur HTML + JavaScript : aucune installation, aucun serveur, pas besoin de Node ni de React.

  • Le plus simple : téléchargez le fichier .html depuis le canvas, puis double-cliquez dessus → il s'ouvre dans Firefox (ou Chrome). C'est tout.
  • Via VSCode : ouvrez le dossier du fichier, clic droit sur le fichier → « Reveal in File Explorer », ou installez l'extension Live Server → clic droit sur le fichier → « Open with Live Server » (utile pour modifier le code et voir le résultat se rafraîchir).
  • Le rendu 3D est fait à la main (projection perspective sur un canvas 2D) : il fonctionne hors-ligne, sans bibliothèque externe.

Limites machine

Toutes les métriques sont calculées en logarithmes (portée = (2^w−2)·log₁₀2, jamais la valeur absolue) : même avec w = 24 bits d'exposant (portée ~10⁷·²⁶⁰), aucun dépassement de float64 n'est possible dans le calcul lui-même.
